# Competition Notes

This repository was developed for the 2026 National Institute of Korean Language (NIKL) AI Malpyeong Writing Scoring Evaluation.

## Task

The task evaluates a model's ability to score a completed Korean argumentative essay. The model receives a writing prompt and an essay and returns scores and rationales for three dimensions:

- Content
- Organization
- Expression

## Dataset sizes

| Split | Samples |
|---|---:|
| Train | 2,000 |
| Validation | 400 |
| Test | 400 |

The test set is not publicly released.

## Preliminary evaluation

The preliminary stage combines three metrics:

| Metric | Weight |
|---|---:|
| RMSE | 45% |
| Spearman rank correlation | 45% |
| LLM Judge | 10% |

## Arena

After the preliminary round, models moved on to AI Malpyeong Arena, where Korean-language experts compared the scoring results and rationales generated by pairs of anonymized models. This project's submission took part in this stage.
